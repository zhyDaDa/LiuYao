## 一、年月日时干支（万年历）

### 1. 年干支
- **算法**：用公历年份 `Y`，`GZ = (Y - 3) % 60`，若余数为0则对应癸亥(序数59+1=60？统一用0-59)。
- **序数表**：天干10个(甲1..癸10)，地支12个(子1..亥12)。干支序数 `n` (0～59)。  
  天干序号 = `n % 10` (甲0,乙1...癸9)；地支序号 = `n % 12` (子0,丑1...亥11)。
  直接转为字符即可。
- 例：2026年 -> (2026-3)%60 = 23 -> 丙戌年 (天干2→丙，地支11→戌)。

### 2. 月干支（节气月）
- 月地支固定：寅(正月/立春)、卯(二月/惊蛰)、辰(三月/清明)、巳(四月/立夏)、午(五月/芒种)、未(六月/小暑)、申(七月/立秋)、酉(八月/白露)、戌(九月/寒露)、亥(十月/立冬)、子(十一月/大雪)、丑(十二月/小寒)。
- 月天干用 **五虎遁**（由年干推正月寅月天干）：
  - 年干甲或己 → 寅月为丙寅
  - 年干乙或庚 → 寅月为戊寅
  - 年干丙或辛 → 寅月为庚寅
  - 年干丁或壬 → 寅月为壬寅
  - 年干戊或癸 → 寅月为甲寅
- 查出寅月天干后，按天干顺序顺推即可得任何月的干支。
- **节气判断**：须精确到节气交节时刻才能定月份。代码可内置节气表或简化公式（如按日期间隔近似），但严格排盘建议接入专业节气库。  
  例：2026年立春2月4日，之后为寅月，年干丙→正月庚寅月。

### 3. 日干支
- **公式法**：取年份后两位数字 `Y`，先算当年1月1日的干支基数。
- `A = (Y + 7) * 5 + 15 + floor((Y + 19) / 4)`。
- `B = A % 60`。
- 计算目标日期是当年的第几天 `C`，1月1日为第1天；需正确处理平闰年、各月天数。
- `M = (B + C) % 60`，若余数为0则按60处理。
- `M` 为六十甲子序数（1～60）；转成代码下标时使用 `M - 1`。
- 例：2026年5月23日，`Y=26`，`A=191`，`B=11`，`C=143`，`M=34`，对应 **丁酉日**。

### 4. 时干支
- 时辰地支按24小时固定：23-1子时、1-3丑时、3-5寅时… 21-23亥时。
- 时天干用 **五鼠遁**（由日干推子时天干）：
  - 日干甲或己 → 子时为甲子
  - 日干乙或庚 → 子时为丙子
  - 日干丙或辛 → 子时为戊子
  - 日干丁或壬 → 子时为庚子
  - 日干戊或癸 → 子时为壬子
- 得出子时天干后，顺推即可得到该时辰天干。

## 二、旬空（空亡）

- 根据 **日干支** 计算。
- 六十甲子每10个为一旬，共6旬：
  - 甲子旬：空 **戌、亥**
  - 甲戌旬：空 **申、酉**
  - 甲申旬：空 **午、未**
  - 甲午旬：空 **辰、巳**
  - 甲辰旬：空 **寅、卯**
  - 甲寅旬：空 **子、丑**
- 算法推导：
  1. 取得日干支的60甲子序数 `n` (0~59)。
  2. 旬首序数 `p = n - (n % 10)`。
  3. 旬首地支序数 `d = p % 12` (子=0)。
  4. 空亡的两个地支序数：`(d + 10) % 12` 和 `(d + 11) % 12`。
- 例：日干支序数23 (丙戌)，n%10=3，p=20，d=20%12=8 (辰? 酉? 核对：0子，8是申? 地支：0子,1丑,2寅,3卯,4辰,5巳,6午,7未,8申,9酉,10戌,11亥。d=8→申，空亡(8+10)%12=6→午，(8+11)%12=7→未。所以旬空午未。丙戌在甲申旬，空午未，正确。

## 三、六爻纳支与五行

### 1. 八纯卦纳支表（六爻地支）
阳卦顺排，阴卦逆排。每卦分内外两卦，内外地支对应。

| 卦名 | 内卦初爻 | 二爻 | 三爻 | 外卦四爻 | 五爻 | 上爻 |
|------|---------|------|------|---------|------|------|
| 乾   | 子      | 寅   | 辰   | 午      | 申   | 戌   |
| 震   | 子      | 寅   | 辰   | 午      | 申   | 戌   |
| 坎   | 寅      | 辰   | 午   | 申      | 戌   | 子   |
| 艮   | 辰      | 午   | 申   | 戌      | 子   | 寅   |
| 坤   | 未      | 巳   | 卯   | 丑      | 亥   | 酉   |
| 巽   | 丑      | 亥   | 酉   | 未      | 巳   | 卯   |
| 离   | 卯      | 丑   | 亥   | 酉      | 未   | 巳   |
| 兑   | 巳      | 卯   | 丑   | 亥      | 酉   | 未   |

### 2. 重卦纳支
- 本卦、变卦都由上卦+下卦组成。
- **纳支规则**：直接把下卦当作内卦，上卦当作外卦，从表中取地支。
- 例：水雷屯，上坎下震。内卦震 → 初爻子、二爻寅、三爻辰；外卦坎 → 四爻申、五爻戌、上爻子。

### 3. 地支五行与卦宫五行
- **地支五行**：亥子水，寅卯木，巳午火，申酉金，辰戌丑未土。
- **八宫五行**（卦宫即八纯卦的五行）：
  - 乾、兑 → 金
  - 震、巽 → 木
  - 坎      → 水
  - 离      → 火
  - 艮、坤 → 土

## 四、定世应、认卦宫

对于起出的本卦六爻（0阴、1阳），按以下规则找出世爻位置和所属卦宫。

### 1. 三组同位爻比较
- **天位**：六爻 & 三爻
- **人位**：五爻 & 二爻
- **地位**：四爻 & 初爻
- 同性（同阴或同阳）记为0，异性记为1，得到 (天, 地, 人) 三元组。

### 2. 三元组 → 世爻 映射表

| (天,地,人) | 说明 | 世爻位置 |
|------------|------|----------|
| (0,0,0)    | 全同 | 六爻     |
| (0,1,0)    | 天同、地异、人同 | 初爻 |
| (0,1,1)    | 天同、地异、人异 | 二爻 |
| (1,1,1)    | 全异 | 三爻     |
| (1,0,1)    | 天异、地同、人异 | 四爻 |
| (1,0,0)    | 天异、地同、人同 | 五爻 |
| (1,1,0)    | 天异、地异、人同 | 四爻 (游魂) |
| (0,0,1)    | 天同、地同、人异 | 三爻 (归魂) |

- 应爻规则：世在初应四，世在二应五，世在三应上，世在四应初，世在五应二，世在上应三。

### 3. 卦宫确定
- **世在初、二、三、六爻**：卦宫 = 本卦的 **上卦**（外卦）。
- **世在四、五爻（含游魂四世）**：卦宫 = 本卦 **下卦（内卦）全部变爻**（阴变阳、阳变阴）后得到的那个三画卦。
- **归魂卦（世在三，三元0,0,1）**：卦宫 = 本卦的 **下卦**（内卦）。
- 得到卦宫后，查八纯卦表即得宫卦五行。

**变卦宫位**：变卦直接由本卦动爻改变后生成，其宫位按相同规则判定。

## 五、排六亲

六亲是根据 **“我”（卦宫五行）** 与 **爻的地支五行** 的生克关系：

| 关系       | 六亲 |
|------------|------|
| 生我       | 父母 |
| 我生       | 子孙 |
| 克我       | 官鬼 |
| 我克       | 妻财 |
| 同我       | 兄弟 |

- 本卦六亲：用本卦卦宫五行配本卦各爻地支五行。
- 变卦六亲：用变卦卦宫五行配变卦各爻地支五行（若动爻，则标在该动爻变出的变爻旁）。

例：乾宫金，爻为子水 → 金生水，我生，故为“子孙”。

## 六、排六神（六兽）

六神按 **日干** 起，从 **初爻开始**，固定循环排列：  
**青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武**

- **日干对应初爻六神**：
  - 甲、乙日 → 青龙
  - 丙、丁日 → 朱雀
  - 戊 日    → 勾陈
  - 己 日    → 螣蛇
  - 庚、辛日 → 白虎
  - 壬、癸日 → 玄武
- 初爻定好后，按上述顺序向上排：二爻朱雀/勾陈…（保持循环顺序，到头后回到青龙）。

## 完整排盘逻辑链

1. **确定时间四柱**：年、月、日、时干支。
2. **计算旬空**：由日干支得出。
3. **起卦得本卦、变卦与动爻**（摇卦或设定）。
4. **安世应、定卦宫**：比较六爻同位，得出世应，定本宫与变宫，获取五行。
5. **纳地支**：由本卦、变卦的上下卦查表，给六爻装上地支。
6. **排六亲**：卦宫五行 vs 爻地支五行，排出本卦六亲和变卦六亲。
7. **排六神**：依日干定初爻六神，顺次装列。
8. **组合显示**：形成完整排盘。

以上规则完全基于干支数理与逻辑判定，不依赖主观经验，可直接编写程序实现。
